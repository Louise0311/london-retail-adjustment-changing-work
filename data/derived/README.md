# Reproducible TfL derivatives

These files are generated by `notebooks/01_Data_Audit_Spatial_Framework.ipynb` from the public TfL annualised entry/exit tables and public Underground station-point geometry.

They contain the station-level Monday and Friday ratios, annual deficits, cumulative 2023-2025 commuter-demand shock score, rank, Top-100 flag and station geometry. They do not contain Green Street data or Green Street-derived information.

The CSV geometry field is stored as WKT for compatibility with downstream notebooks. Equivalent GeoJSON files are included for direct GIS inspection.
