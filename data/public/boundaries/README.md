# Spatial boundaries

`London_Office_Markets_V1.geojson` contains the publicly available office-market polygons used to construct the five core Central London office submarkets. `Underground_Stations.geojson` contains public station point geometry used for spatial matching. The folder also includes the May 2024 local-authority boundaries and the London subset of 2021 MSOA boundaries required by the published notebooks.

These files are provided as source geometry. Derived study selections and any analysis output that incorporates safeguarded data are not included.
